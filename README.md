# My Messenger — Real-Time Messaging Platform

A full-stack, real-time messaging application built with Next.js, React, and TypeScript. Featuring user authentication, instant messaging, conversation management, and a modern responsive interface.

## ✨ Features

- Real-time messaging and conversation updates
- Private conversations and contact management
- Message editing, deletion, and read status
- User search and profile management
- File and media upload integration
- Responsive and interactive chat interface

## 🛠️ Tech Stack

**Frontend**
- Next.js, React, TypeScript
- Tailwind CSS, Framer Motion, Radix UI
- TanStack React Query, React Hook Form

**Backend & Database**
- Next.js API Routes
- MongoDB, Mongoose
- JWT Authentication
- Socket.IO

**Media & Integrations**
- UploadThing
- Cloudinary
- Kavenegar (OTP Service)

## 🚀 Getting Started

Clone the repository:

```bash
git clone <repository-url>
cd my-messenger
```

Install dependencies:

```bash
npm install
```

Configure the required environment variables for MongoDB, authentication, real-time services, and media integrations in a local `.env` file.

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
